# Portal de Leads

Site para os representantes pedirem bases de leads da Leads2b e atualizarem o status de cada contato.
O time de Inside Sales aprova cadastros, importa a planilha da Leads2b em cada pedido e acompanha o retorno das lojas.

- `index.html`, `css/`, `js/`: o site (GitHub Pages)
- `config.js`: endereço e chave pública do Supabase (sem eles, o site abre em modo demonstração)
- `supabase/schema.sql`: banco de dados e regras de acesso (rodar no SQL Editor do Supabase)

O passo a passo completo de instalação e uso está no documento entregue junto com este arquivo.
